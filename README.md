# konta-rulebook

Legislația fiscală a Republicii Moldova, sub formă de date: cote, plafoane, termene, clasificări.
Fiecare cifră are data de la care se aplică și trimiterea la actul normativ din care provine.

> **Atenție: toate datele de aici sunt ciorne neverificate.** Au fost confirmate din publicațiile
> Ministerului Finanțelor, SFS și CNAS, dar nimeni nu le-a citit încă în Codul fiscal propriu-zis.
> Nu le folosiți pentru declarații reale până nu sunt aprobate de un contabil autorizat.

## De ce este public

Întrebarea corectă pentru orice program nou de contabilitate este: *„De unde știu că impozitele
sunt calculate corect?”* Răspunsul nostru: citiți-le aici. Dacă găsiți o greșeală, deschideți un
„issue” sau propuneți o corectură.

## Cum funcționează, pe scurt

- **Nicio cifră fără sursă.** Fiecare valoare trimite la legea sau hotărârea din care provine.
- **Legea se schimbă în timpul anului, și asta se vede.** De exemplu, plafonul de înregistrare TVA
  s-a schimbat de două ori în 2026; fiecare schimbare este un set separat, cu data ei.
- **Ce a fost aprobat nu se modifică.** O corectură se adaugă ca set nou, ca să se poată vedea
  oricând ce reguli s-au aplicat la o declarație deja depusă.
